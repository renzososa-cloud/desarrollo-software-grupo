## 📋 Descripción

Repositorio grupal destinado al desarrollo, documentación y entrega de los trabajos prácticos y proyectos integradores de la cátedra **Desarrollo de Software**. El objetivo del espacio es centralizar la evolución técnica del equipo desde los fundamentos de Programación Orientada a Objetos hasta la construcción de aplicaciones backend empresariales con persistencia de datos y arquitectura en capas.

---

## 🛠️ Tecnologías y Herramientas

* **Lenguaje:** Java
* **Frameworks y Persistencia:** Spring Boot, Spring Data JPA, Hibernate, JPQL
* **Bases de Datos:** MySQL / H2 Database
* **Control de Versiones y Entorno:** Git, GitHub, Gradle / Maven
